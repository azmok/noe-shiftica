# Airbnb Newsroom Japan

Audited November 25, 2026. The [Japanese fall update](https://news.airbnb.com/ja/airbnb-2026-fallupdate) is the initial reference. Its saved HTML and linked public stylesheets were measured in Windows Chromium. Metrics describe this article template. Cereal webfonts were not loaded in the offline measurement, so the font family is the declared CSS stack.

| Role | 1440px | 1024px | 768px | 390px |
| --- | --- | --- | --- | --- |
| Article title | 46 / 52 / 500 | 46 / 52 / 500 | 32 / 36 / 500 | 26 / 30 / 500 |
| Body paragraph | 18 / 28 / 400 | 18 / 28 / 400 | 18 / 28 / 400 | 16 / 24 / 400 |
| Section heading | 32 / 36 / 500 | 32 / 36 / 500 | 26 / 30 / 500 | 26 / 30 / 500 |
| Body width | 632px | 624px | 453.33px | 342px |
| Paragraph bottom margin | 24px | 24px | 24px | 24px |
| Section heading margins, top and bottom | 48 / 28px | 48 / 28px | 48 / 24px | 48 / 24px |

Type measurements are size / line height / weight. Letter spacing is normal for all three roles. The declared stack is Cereal, Cereal Fallback, sans-serif. The measured text color is `#222222`.

The body remains regular weight and holds the same 24px paragraph space at every sampled width. A large heading can mark a section without the dense weight of Apple Newsroom's 700-weight heading. At 1440px both have a similar Japanese line measure of about 34 full-width characters, but this Airbnb article uses an 18px body with a 28px line box. The additional line space and 48px before section headings give the text more room vertically.

The [local catalog](../../apps/design-catalog/README.md) applies those headline, paragraph, and section values to the same sample material as the Apple preset. Its local rounded font stack and accent color are preview choices. The two-column experiment is available as a separate layout control for either theme.
