保存の結果

  
    

    


  
    
    
    保存の前に：画像が見つかりません
    
    
    本文が使っている次の画像が、GitHub 上に見つかりません（ファイルが無いか、パスが違う）。このまま保存すると GitHub には保存されますが、サイトへの下書き送信は失敗します（画像が全部そろわないと送れないため）。
    
    
      
    
      画像を Working Copy などで記事フォルダに入れるか、本文のパスを直してから、もう一度保存してください。
      
    
      
      
      
    
      
  
      
      


  
      
    
      記事の移動・削除
      
    
      
    
      
    
    
      GitHub の main に commit します（下書きブランチがあれば、そちらも一緒に動かす／消す）。サイトにある記事（DB）はそのまま残ります。dev/ や blog/ の直下に移した記事は、main の Action でサイトに送られます（frontmatter の status に従う）。
      
    
      
      
      
      
    
      
  
      
      


  
      
    
      設定
      
    
      
    
      
      
      
      
      リポジトリの URL と GitHub の鍵は、管理画面の「Markdown Post Manager 設定」で入れます。鍵はサーバーにだけ暗号化して保存され、このブラウザには渡りません。
      
      
      設定を開く →
      
    
      
    
      
      
      
      azmok/noe-posts だけに「Contents：Read and write」を付けた鍵。この端末の中だけに保存され、外には送られません（GitHub との通信だけに使う）。
