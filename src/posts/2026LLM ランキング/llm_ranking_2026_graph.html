📊 チャット版 採点基準と注記

  • Gemini 3 Pro について：API版は2026年3月9日に廃止・シャットダウン済み。ただしチャット UI の「Thinking (3 Pro)」ラベルは 3.1 Pro が引き継ぎ継続提供中。米国の無料ユーザーも日次上限付きで「Thinking (3 Pro)」利用可能。AI Pro（$19.99/月）で拡張枠・Ultra で 1,500 プロンプト/日
  • Gemini 3.1 Pro は2026年2月19日リリース。3段階 thinking_level（Low/Medium/High）を導入し、High モードで「Deep Think Mini」が発動。前世代 3 Pro の high≒3.1 Pro の medium に相当
  • チャット Elo：LMArena (arena.ai) Text Leaderboard の Elo スコア（5,440,800 票・2026年3月6日時点）
  • コーディング Elo：Arena.ai Code Leaderboard の Elo スコア（agentic coding, HTML/React タスク）
  • レイテンシ：体感応答速度（各社公式チャット UI）および Artificial Analysis 計測値を参考
  • Gemini 3 Flash は知性スコアでは Sonnet 4.6 に劣るが、無料提供・超高速で利便性が高いため6位
  • DeepSeek はオープンウェイトで完全無料利用が可能なため、コスパ面から7位に選出
  • GPT-5.3 Instant（3月3日リリース）は全 ChatGPT ユーザーのデフォルトモデルに昇格。API名 gpt-5.3-chat-latest。幻覚率 -26.8%（Web検索時）を達成
  • GPT-5.3 Codex (xhigh) はコーディングエージェント特化モデルのため API 版 4位に収録し、チャット版では GPT-5.3 Instant を別エントリとして追加
  • GPT-5.2 Instant は2026年6月3日に退役予定。旧 GPT-5 Instant/Thinking は2月13日に既に退役済み
