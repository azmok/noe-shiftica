前回、「AI社員」の実体は標準機能の組み合わせだと書きました。

今回は、それを実際に手を動かして確かめます。 読むだけでなく、自分の手元で動かせます。

プログラミングの知識は、まったく必要ありません。
コードを書くのも、ファイルを作るのも、全部AIがやります。
あなたがやるのは、この記事にある文章を貼り付けることだけです。

「そんなうまい話が」と思うかもしれませんが、2026年の今はこれが普通です。むしろこの事実こそが、高額な講座が不要である理由でもあります。

今回やること

2人のAIが役割を分けて働く、最小のチームを作ります。

あなた「海の見えるカフェのページを作って」
      ↓
デザイナー役のAI ── どんなページにするか考える
      ↓ 考えた内容を渡す
コーダー役のAI  ── 実際のWebページを作る
      ↓
Webページが完成する

テーマを1つ伝えるだけで、勝手に構成が考えられ、勝手にページが出来上がります。準備も含めて30分ほどです。

そして完成したあと、中身のコードを読みます。 ここが今回の本題です。

先に、お金の話をします

気持ちよく進めるために、費用の話を最初に済ませておきます。

結論から言うと、月3,000円ほどのサブスクを1つ契約している状態が、いちばん快適です。

会社プラン月額の目安
GoogleGoogle AI Pro約3,000円
AnthropicClaude Pro約3,000円
OpenAIChatGPT Plus約3,000円

どれか1つで大丈夫です。 すでにChatGPTやClaudeを契約している方は、追加の費用はかかりません。

無料でも試せますが、使える回数がかなり限られています。途中で止まると、それだけで嫌になります。最初の一歩でつまずかないために、月3,000円は妥当な投資だと僕は考えています。

そして、このシリーズで扱っている高額な講座は数十万円という価格帯でした。桁が2つ違います。

⚠️ 料金は変わりやすい分野です。上記は2026年8月時点の目安なので、契約前に各社の公式ページで確認してください。

準備編

ここが少し長いですが、一度やれば次回からは不要です。

準備 1
フォルダを作る

デスクトップなど分かりやすい場所に、空のフォルダを1つ作ります。 名前は ai-team にしてください。右クリックから「新規フォルダ」を選ぶだけです。

⚠️ なぜ先に作るのか：AIに「フォルダを作って」と頼むと、パソコンの個人フォルダ全体がAIから見える状態になることがあります。関係のないファイルまで読み込まれる原因になるので、先に作って範囲を区切っておきます。

準備 2
Antigravity IDEを入れる

契約している会社に関係なく、全員がインストールします。 「IDE」は、ファイルの中身を見たり書き換えたりするための道具です。

antigravity.google を開いてください。Windows・Mac・Linuxすべて対応、無料です。

⚠️ 注意：ダウンロードページには、似た名前のものが4つ並んでいます。

名前何のためのものか
Antigravity IDE← 今回入れるのはこれです
Antigravity 2.0複数の作業をまとめて管理するアプリ
Antigravity CLIGoogleと契約している方が、後で追加します
Antigravity SDK開発者向けの部品

インストールしたら起動して、メニューから「ファイル」→「フォルダを開く」で、準備1で作った ai-team を選んでください。

📌 初回起動時にGoogleアカウントを求められることがありますが、無料のアカウントで大丈夫です。今回IDEは「ファイルを見る道具」としてだけ使います。

準備 3
ターミナルを開く

メニューから「ターミナル」→「新しいターミナル」を選んでください。画面の下に新しい欄が開きます。

怖がる必要はありません。打つコマンドは全部この記事に書いてあります。 コピーして貼るだけです。

💡 キーボードなら Ctrl + @ でも開けます。

準備 4
CLIを起動する

契約している会社によって分かれます。 自分の契約に合うところだけ読んでください。

▸ Googleと契約している方

公式ページの手順でAntigravity CLIをインストールします。Windowsの場合はこれです。

curl -fsSL https://antigravity.google/cli/install.cmd -o install.cmd && install.cmd && del install.cmd

インストール後、ターミナルを閉じて開き直してから、次を実行します。

agy

▸ Anthropic（Claude）と契約している方

brew install --cask claude-code

Windowsの方は公式手順をご覧ください。インストール後、次を実行します。

claude

▸ OpenAI（ChatGPT）と契約している方

# Mac / Linux
curl -fsSL https://chatgpt.com/codex/install.sh | sh

# Windows（PowerShell）
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

インストール後、次を実行します。

codex

起動したら「Sign in with ChatGPT」を選び、契約中のアカウントでログインしてください。

どのCLIでも、起動に成功すると文章を入力できる状態になります。

準備 5
APIキーを取得する

最後に「APIキー」を取ります。作ったプログラムがAIを呼び出すための鍵です。

ここは混乱しやすいので、はっきり分けておきます。

CLI（agy / claude / codex）
  → AIがあなたの代わりにファイルを作る
  → 契約しているサブスクで動く

APIキー
  → 出来上がったプログラムがAIを呼ぶ
  → サブスクとは別の仕組み。別途取得が必要

💡 なぜ別なのか：サブスク用のログインは、CLI自身が使うための認証です。各社とも、この認証を自作プログラムから流用することを規約で禁止しています。専用の鍵を別途取得してください。

使う予定の会社のものを、1つだけ取得します。

▸ Google
  https://aistudio.google.com/apikey
  →「APIキーを作成」（AIza... で始まる文字列）

▸ Anthropic
  https://console.anthropic.com/settings/keys
  →「Create Key」（sk-ant-... で始まる文字列）

▸ OpenAI
  https://platform.openai.com/api-keys
  →「Create new secret key」（sk-... で始まる文字列）

💰 今回作るものは、1回動かしてもごくわずかな金額です。正確な単価は各社の公式ページで確認してください。

実装編（3ステップ）

STEP 1
作ってもらう

起動したCLIに、次の文章をそのまま貼り付けてください。 どの会社のCLIでも同じです。

Pythonで「役割を持つAIエージェント」の最小構成を作ってください。
私はプログラミング初心者なので、必要なものはすべて自動で用意してください。
今開いているこのフォルダを、作業フォルダとして使います。

## 対応してほしい会社（3社すべて）
Google（Gemini）、Anthropic（Claude）、OpenAI（ChatGPT）の3社に
対応させてください。

【手順の前提】
まず .env ファイルを作ります。この時点では、APIキーはまだ
1つも設定されていません。3社分の行をすべてコメントアウトした
状態で用意してください。
私があとで、自分が使う会社の行だけコメントを外して、
実際のキーを貼り付けます。

そのうえでプログラム側は、実行された時に .env を読み込み、
「コメントが外されている行はどれか」を見て、
その会社のAPIを使う、という作りにしてください。

## 使用するモデルについて（重要）
- モデル名は、あなたの記憶だけで決めないでください
- 検索ツールを実際に使って、次の3社それぞれの公式ドキュメントを調べ、
  現時点で提供されている「標準的な」最新モデル名を確認してください
  - Google: ai.google.dev
  - Anthropic: docs.claude.com
  - OpenAI: platform.openai.com/docs/models
- 確認した3社分のモデル名を、コード内に辞書として持たせてください
- 確認せずに記憶だけで書くと、提供終了したモデルを指定してしまい、
  実行時にエラーになることがあります

## 環境
- パッケージ管理には uv を使う（未インストールなら導入から行う）
- 必要なパッケージは3社分すべて
  （google-genai、anthropic、openai、python-dotenv）

## 作ってほしいファイル

### .env
次の内容で作成してください。キーはまだ入れず、3行すべてを
コメントアウトした状態にしてください。

  # 使う会社の行だけ、先頭の # を外してキーを貼ってください

  # GEMINI_API_KEY=ここにキーを貼ってください
  # ANTHROPIC_API_KEY=ここにキーを貼ってください
  # OPENAI_API_KEY=ここにキーを貼ってください

### .gitignore
.env と output/ と .venv/ を除外する

### agents.py
- 実行時に .env を読み込む
- 3つのキーのうち、コメントが外されて有効になっているのは
  どれかを判定し、対応する会社のクライアントを用意する
- どれも有効でない場合は、分かりやすい日本語のエラーを出す
- agent(role, task, model=None) という関数を1つ定義する
  - model 未指定なら、確認済みの最新モデル名を使う
  - 3社のAPIの違いは、この関数の中で吸収する
- 戻り値は、会社によらず常にテキストのみ

### roles.py
DESIGNER と CODER という2つの文字列を定義する
- DESIGNER: UIデザイナー。渡されたテーマから、1枚のWebページの
  構成・配色・フォント・各セクションの文言を決める。
  仕様だけを日本語で書き、コードは書かない
- CODER: フロントエンドエンジニア。渡された仕様を、
  外部ファイルに依存しない1枚のHTMLとして実装する。
  レスポンシブ対応。出力はHTMLコードのみ

### main.py
- THEME という変数にテーマを書く
  （初期値は「海の見える個人経営のカフェ。落ち着いた大人向けの雰囲気」）
- デザイナーを呼んで仕様を作り、output/design.md に保存
- その仕様をコーダーに渡してHTMLを作り、output/index.html に保存
- AIの返答からコードフェンスを取り除く処理を入れる
- 各工程の進行状況を日本語で分かりやすく表示する
- 使用している会社名とモデル名も表示する
- すべて完了したら、標準ライブラリの webbrowser を使って
  output/index.html を自動でブラウザで開く

### README.md
セットアップ手順と実行方法。3社の確認済みモデル名と、
その確認に使った情報源も書いておいてください

## 最後に
- 作ったファイルの一覧と役割を日本語で説明してください
- 確認した3社のモデル名と、情報源を教えてください
- 私が次に何をすればいいかも教えてください

貼り付けたら、あとは待つだけです。3社分のモデル名を調べるところまで、全部やってくれます。

キーを設定する

ここだけが、あなたの手作業です。

画面左のファイル一覧から .env を開いてください。

# 使う会社の行だけ、先頭の # を外してキーを貼ってください

# GEMINI_API_KEY=ここにキーを貼ってください
# ANTHROPIC_API_KEY=ここにキーを貼ってください
# OPENAI_API_KEY=ここにキーを貼ってください

やることは2つだけです。

  1. 自分が使う会社の行だけ、先頭の # と空白を消す
  2. 「ここにキーを貼ってください」を、実際の鍵に置き換える

Googleを使う場合の完成形です。

# 使う会社の行だけ、先頭の # を外してキーを貼ってください

GEMINI_API_KEY=AIzaSy...（あなたの鍵）
# ANTHROPIC_API_KEY=ここにキーを貼ってください
# OPENAI_API_KEY=ここにキーを貼ってください

使わない2行は、そのまま # を付けたままで大丈夫です。 # で始まる行はメモ書き扱いになり、プログラムから無視されます。

⚠️ .env の中身は誰にも見せないでください。鍵が漏れると、他人にあなたの分の料金を使われます。

中身を読んでみる

ここからが本題です。 何かを書く必要はありません。読むだけです。

できあがったファイルを見ると、「AI社員」と呼ばれているものの正体がはっきりします。

役割の正体は、ただの文章

roles.py を開いてみてください。

DESIGNER = """あなたはUIデザイナーです。
渡されたテーマから、1枚のWebページの仕様を決めてください。

- ページ全体の構成（どのセクションを、どの順番で置くか）
- 配色（背景・文字・アクセントの3色を、カラーコードで指定）
- 各セクションに入れる文言の内容

コードは書かないでください。仕様だけを日本語で書いてください。"""


CODER = """あなたはフロントエンドエンジニアです。
渡された仕様を、1枚のHTMLファイルとして実装してください。

- スマホでも崩れないようにする
- 仕様にないものは追加しない
- 出力はHTMLコードのみ。説明文は不要"""

見てのとおり、ただの日本語の文章です。 プログラムらしいものは何もありません。

つまり——「AI社員を作る」とは、こういう文章を書くことでした。

ここを書き換えれば、そのまま別の社員になります。「あなたは経理担当です」と書けば経理係に、「あなたは校正者です」と書けば校正係に。特別な技術は要りません。

💡 うまく書くコツが3つあります。

  1. やってほしくないことを書く——「コードは書かない」のような線引きが、暴走を防ぎます
  2. 出し方を指定する——「日本語で」「HTMLだけ」と書かないと、余計な前置きが混ざります
  3. 具体的に書く——「配色」より「3色をカラーコードで」のほうが精度が上がります

連携の正体は、文字列の連結

次に main.py の、いちばん大事な2行を見てください。

design = agent(DESIGNER, "このテーマで仕様を作って")
result = agent(CODER,    "この仕様を実装して" + design)

2行目に注目してください。+ design という部分があります。

デザイナーの出力を、そのままコーダーへの指示文にくっつけているだけです。

これが「連携」の正体です。特別な仕組みは、どこにもありません。

なぜ、これで役割分担が成立するのか

ここが最も面白いところです。

前回、役割分担の本体は「作業する机を分けること」だと書きました。では、このコードのどこで机を分けているのでしょうか。

答えは、分ける処理を書いていない、です。

AIを呼び出す仕組みは、前回のやり取りを覚えていません。 呼び出すたびに、そのとき渡された内容だけを見て応答します。

つまり呼び出すたびに、机が自動的にまっさらな状態から始まります。

デザイナーが迷った過程も、書きかけて消した案も、コーダーの机には乗りません。届くのは完成した仕様だけです。

特別な仕組みが分けているのではなく、最初から分かれている。

裏を返すと、大事な注意点があります。必要な情報は、毎回きちんと渡さないといけません。 「さっきの仕様で」は通じません。

だから + design という一手間が必要になる。この一手間こそが、机が分かれていることの証拠でもあります。

うまくいかないときは

基本的には、エラーの文章をそのままAIに貼って「直してください」と伝えれば解決します。

💡 1つだけコツがあります。AIはモデル名のような「よく変わる情報」を、古い記憶のまま答えることがあります。直してもらったのに同じ種類のエラーが出る場合は、「検索して確認してから直して」と付け加えてください。

症状どうするか
CLIのコマンドが見つからないターミナルを閉じて開き直してください
「APIキーが見つかりません」.env の # が外れているか確認を
「モデルが見つかりません」「公式サイトを検索して、現在使えるモデル名を確認してから直して」と伝える
「上限に達しました」1分ほど待ってから、もう一度実行を
ページに変な記号が出る「HTMLに余計な記号が混ざっています」と伝える

💡 遠慮なくAIに聞いてください。 「この行は何をしているの？」という質問にも答えてくれます。

まとめ

  • プログラミングの知識がなくても、AIチームは作れる
  • あなたがやったのは、文章を貼るのと、# を外して鍵を貼ることだけ

  • 「連携」の正体は、前の出力を次の指示文にくっつけるだけ

つまり——「AI社員」とは、指示する文章を切り替えているだけのものでした。
