## はじめに：好きなことを始めれば、人生は変わる

結論はタイトルの通りシンプルです。

しかし、これができない。

もしこれで解決するなら、世の中の大半の人はとっくに思い通りの人生を生きているはずです。そうなっていないのには、明確な理由があります。

そもそも私たちは、成長するにつれて好きなことをする時間を削られ、したくないことを強いられる社会システムの中で生きています。気がつけば、

- 好きなことが何かわからない
- 趣味がない
- 仕事や勉強は「しなければいけないこと」、その余暇で好きなことをする

という状態に落ち着いてしまう。これは個人の問題ではなく、構造の問題です。

ではどうすればいいのか。答えは二つです。

1. **現状を把握する**
2. **自己（脳）と外界（社会）の仕組みを知る**

本稿（前編）は **「自己＝脳の仕組み」** を扱います。後編で「外界＝資本主義経済の仕組み」を解説します。

---

## 自分という「乗り物」を知る

人生を「車での旅」に例えてみてください。

ゴールに向かって走るには、まず自分の乗っている車の状態を知る必要があります。エンジンの調子は？タイヤの摩耗は？最高速度は？燃費は？——これがわからなければ、

- 故障している箇所を直すこともできない
- 限界スピードを引き上げることもできない
- 車内をカスタマイズして快適にすることもできない

つまり、**ゴール達成のために何をどう変えればいいかが、永遠にわからない** のです。

ところが多くの人は、自分という乗り物について「運転の仕方をなんとなく知っている」レベルで止まっています。なぜエンジンが動くのか、どんな仕組みで走っているのか、1%も理解していない。これでは改造も修理もできず、結局すべてを「他人任せ・専門家任せ」にせざるを得ません。

自分の心、思考、行動を生み出している **脳** についても、まったく同じ状況です。

> 自分自身を変えられないのは、意志が弱いからではなく、仕組みを知らないからです。

## 脳の構造：意識と無意識

脳の働きを、思い切ってシンプルに整理します。

```
脳
├─ 意識（全体の20〜30%）
│   ├─ 思考
│   └─ 熟考の末の判断
│
└─ 無意識（全体の70〜80%）
    ├─ 情動（感情の自動反応）
    ├─ 脊髄反射
    ├─ 習慣
    ├─ 癖
    ├─ 咄嗟の決断
    └─ 感覚
```

ここで重要な事実があります。

**人間の思考・反応・行動の70〜80%は、無意識が決定しています。**

つまり、私たちが「自分で選んで生きている」と思っている日常は、ほとんどが無意識による自動運転です。意識的に何かを決めている瞬間は、ほんの数%に過ぎません。

学校でも、アルバイトでも、仕事でも、恋愛でも、買い物でも——よほど哲学的な熟考を要する場面以外、私たちはほぼ無意識で生きているのです。

### 意識だけでは、自己を変えられない

この事実を踏まえると、次のような「意識による決意」がいかに無力か理解できると思います。

- 「明日から絶対ダイエットする！」
- 「毎日2時間は必ず勉強する！」
- 「もう二度とネガティブにならない！」

意識でいくら強く決めても、すぐに元に戻ってしまう。なぜなら、行動の70〜80%を支配しているのは無意識のほうだからです。**全体の20%しか持たない意識が、80%の無意識を制圧することは構造的に不可能です。**

意識的な決意で自分を変えようとするのは、**車のハンドルを軽く触っただけで、高速で走るトラックの進路を変えようとする** ようなものです。

自分を本気で変えたいなら、向き合うべきは無意識のほうです。

## 無意識を理解するための4つの基礎概念

ここから、無意識の仕組みを理解するために必要な4つの概念を、順を追って解説します。心理学や認知科学に馴染みがない方でも理解できるよう、噛み砕いて説明します。

### ① スコトーマ（心理的盲点）

**スコトーマ（scotoma）** とは、もともと医学用語で「視野の中に見えていない領域」を指す言葉です。認知科学では、これを「心理的盲点」として応用します。

人間の脳は、目の前にあるすべての情報を処理しているわけではありません。**自分にとって重要だと感じているものだけ** を選んで認識し、それ以外は文字通り「見えていない」のです。

たとえば、あなたが新しい車を買おうとしたとたん、街中で同じ車種ばかり目に入るようになった経験はありませんか？車の数自体が増えたわけではなく、あなたの脳が「重要」と判定したから見えるようになっただけです。

つまり、**「自分が好きなこと」がわからない人は、好きなことが存在しないのではなく、脳のスコトーマで見えなくなっているだけ** ということです。

### ② RAS（網様体賦活系／もうようたいふかつけい）

**RAS（Reticular Activating System）** とは、脳幹にある神経の集まりで、「何を意識に上げて、何を無意識に流すか」を選別するフィルター装置です。

スコトーマを生み出している正体は、このRASです。

RASは、あなたの脳が「重要」と判定したものだけを、無意識の海から意識に引き上げてくれます。逆に「重要でない」と判定されたものは、目の前にあっても気づきません。

ということは——**自分の脳に「これは重要だ」と思わせることができれば、関連する情報やチャンスが見えるようになる** のです。これが「無意識の書き換え」の第一歩です。

### ③ コンフォートゾーンとホメオスタシス

**コンフォートゾーン** とは、自分にとって「居心地のいい状態」のことです。今の年収、今の人間関係、今の体型、今の生活リズム——これらすべてが、あなたのコンフォートゾーンです。

そして人間の脳には **ホメオスタシス（恒常性維持機能）** という仕組みが組み込まれています。これは「現状を維持しようとする力」です。体温が一定に保たれるのと同じように、心の状態も「いつもの自分」に引き戻そうとします。

ダイエットがリバウンドするのも、副業を始めても三日で続かなくなるのも、これが原因です。意識で「変わろう」と決意しても、ホメオスタシスが無意識のレベルで「いつもの状態に戻れ」と強烈に引き戻してくるのです。

つまり、**コンフォートゾーンの外側に出ようとしても、ホメオスタシスが自動的に内側へ引き戻す。** これが「人が変われない」最大のメカニズムです。

逆に言えば、**コンフォートゾーンそのものを未来側に移動させてしまえば**、ホメオスタシスは新しいコンフォートゾーンを維持するために働きます。引き戻す力が、今度は前進させる力に変わります。

### ④ 重要性関数とWant-to／Have-to

**重要性関数** とは、「あなたが何を重要だと感じているか」の優先順位リストのようなものです。RASが情報を選別する基準も、ホメオスタシスがどこを守るかも、すべてこの重要性関数で決まります。

そして重要性関数は、大きく2種類に分かれます。

- **Want-to（やりたい）**：自分の内側から湧き上がる衝動。誰に言われなくても夢中になれること。
- **Have-to（やらねばならない）**：外から強制されたもの。やらないと罰や不利益があるからやること。

現代社会は、Have-toで埋め尽くされています。学校の宿題、職場の業務、世間体、親の期待——これらが重要性関数の上位を占めると、本来あなたが心の奥で「やりたい」と思っているWant-toは、スコトーマの向こう側に隠されてしまいます。

**「好きなことがわからない」状態とは、重要性関数がHave-toで埋め尽くされ、Want-toにスコトーマがかかった状態** なのです。

## 「才能」という幻想

ここで、もうひとつ重要な視点を共有させてください。

世の中では「才能がある人」と「才能がない人」がいるかのように語られます。しかし、認知科学の視点から見ると、**「才能」という概念そのものが幻想** です。

考えてみてください。

- 生まれた瞬間から言葉を流暢に話せる赤ちゃんはいません。
- 生まれた瞬間からプロ野球選手のように打席に立てる人もいません。
- 生まれた瞬間からピアノを弾ける人もいません。

すべての人間は、ほぼ同じ「デフォルト初期値」からスタートします。違いは、そこから **どれだけ自分の時間を投じて、その対象に注力してきたか** だけです。

「才能がある」と評される人は、単に **その対象が自分のWant-toと一致していたため、長時間注力することが苦にならなかった** だけのことです。重要性関数の上位に置けたから、無意識が勝手に伸ばしてくれただけ。

逆に言えば、**自分のWant-toに沿って注力する対象を選べば、誰もが「才能がある」と評される領域に到達できる** のです。

> 才能とは、生まれつきの差ではなく、初期値を伸ばしたか伸ばしていないかの差に過ぎません。

なお、本稿では一般的によく使われる「努力」という言葉を意図的に避け、「注力」と表現しています。「努力」には「やらねばならない（Have-to）」のニュアンスが混ざりがちですが、**「注力」とは、その対象に対して自分の時間を投じ、没頭してきたこと** という、もっとニュートラルで本質的な状態を指します。

Want-toに沿った注力は、本人にとって「努力」とすら感じられません。むしろ夢中で楽しい時間です。これこそが、長期的に圧倒的な成果を生む唯一の構造です。

## 前編のまとめ

ここまでの内容を整理します。

| 概念 | 要点 |
|------|------|
| 意識と無意識 | 行動の70〜80%は無意識が決定。意識だけでは変われない |
| スコトーマ | 重要だと感じないものは見えなくなる「心理的盲点」 |
| RAS | 何を意識に上げるかを選別する脳のフィルター |
| コンフォートゾーン／ホメオスタシス | 現状を維持しようとする強力な引き戻し機能 |
| 重要性関数／Want-to・Have-to | 何を重要視するかが、すべてを決める |
| 才能 | 幻想。Want-toに沿った注力量の差に過ぎない |

人生を変えるとは、意志の問題ではありません。**自分という乗り物（脳）の仕組みを知り、無意識を書き換えることで、勝手に行動が変わり、結果が変わる** ——これが本質です。

そして無意識の書き換え方さえ理解し実践すれば、性格、スキル、脳力、物事への反応、習慣、人生のステージ、すべてを変えることができます。具体的な書き換え方は、本シリーズの中で順次解説していきます。

## 次回予告：後編「外界編」

前編では「自己＝脳の仕組み」を扱いました。

しかし、自分という車の仕組みを知っているだけでは、ゴールには到達できません。**どんなルールの道を走っているのか**——つまり外界の仕組みも知る必要があります。

砂漠を走るのか、サーキットを走るのか、一般道なのかで、最適な戦略はまったく異なります。ルールを知らずにゲームをプレイするのは、麻雀のルールを知らずに卓に座るようなものです。

を解説します。

自己（脳）と外界（社会）の両輪が揃ったとき、初めて思い通りの人生をデザインする土台が完成します。後編もお楽しみに。
